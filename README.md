# OpsPilot — Agentic IT Incident Copilot

Local incident investigation with traceable retrieval, supervised ticket classification,
and durable human approval. Implementation is in progress; see PROGRESS.md.

Python 3.13 · uv · FastAPI · SQLite · LangGraph · scikit-learn · Streamlit

```powershell
uv sync
uv run opspilot version
uv run pytest
```
